# 能碳监测平台

**面向算力工业园区的低碳算力能碳分析平台。**

跑在你自己电脑上的分析工具。它的核心思路是**把算力园区当工厂看**：

| 传统工业园区 | 算力工业园区 |
|---|---|
| 车间 | 机房 / 集群 |
| 生产线 | 服务器机型（异构） |
| 原料 | 电力（含绿电） |
| **产品** | **Token** |
| **单位产品碳排** | **每百万 Token 碳足迹** ← 核心指标 |

支持 Windows 和 macOS。

> **它不是一个能碳数据平台。**
> 存数、画图、出报表只是手段。它真正做的是**分析能碳数据的差异性、时序性、不稳定性**——
> 回答「为什么这批任务比那批费电」「绿电来的时候我在用吗」「这个波动是正常的还是出事了」，
> 最后折算成一个能对外说的数字：**每百万 Token 排多少碳**。

📖 **完整产品文档见 [CLAUDE.md](./CLAUDE.md)** —— 分析方法、计算公式、技术方案、开发路线图。

## 它要回答的三个问题

平台不是功能的堆砌，它围绕三个具体问题设计：

**🔍 问题一 · 谁在什么时候费电，机器是不是闲着**
什么时段、跑哪些模型能耗最高？空置率多少——有多少卡装了没跑任务、闲着还在耗待机电？哪些时段负荷突然增高？

**🔍 问题二 · 风光储到底有没有发挥作用**
风电、光伏、储能是真发挥了作用，还是装了看着好看？能耗高频出现的原因是什么？

> ⚠️ 储能尤其要小心：它有往返效率损失。如果充电时段不够干净、放电时段不够脏，**储能会净增碳而不是减碳**。平台会把这个净值算出来，不默认它一定有用。

**🔍 问题三 · 分时段碳足迹，以及使用频率对寿命和回收的影响**
不同时段碳足迹差多少？使用频率如何影响服务器的生命周期成本？如何影响回收和重复利用？

## 核心指标

| 指标 | 单位 | 服务于 |
|---|---|---|
| **每百万 Token 碳足迹** | gCO₂e/MTok | 对外交代 · 问题三 |
| **空置率 / 空载能耗占比** | % | 问题一 |
| **储能净减碳量** | tCO₂e | 问题二（**可能为负**） |
| **等效寿命消耗率** | % | 问题三 |
| 绿电利用比例 | % | 问题二（分时段算才有意义） |
| 能效 | Tokens/kWh | 机型对比 |

> ⚠️ 每百万 Token 碳足迹**必须连口径一起说**，否则数字无法比较：
> `42.3 gCO₂e/MTok（地域法，输入+输出，含PUE，含隐含碳按等效运行小时摊销，因子v1.2，2026年7月）`

## 关于数据安全（重要，先读这段）

这个平台会用到云端 AI 模型，所以必须把边界说清楚：

**留在你本机的**
- 所有原始明细数据（逐条功耗记录、设备序列号、机房位置、文件原文）
- 整个数据库 `data/app.db`

**会发给 AI 模型的**
- 只有聚合统计量，比如「7月3日 14:00-18:00 平均功率 420kW，较基线高 38%」
- 每次发送前，界面会**完整展示将要发出的内容**，你确认才发

**如果你不想用 AI**
- 设置里有**纯本地模式**开关。关掉之后，测算、图表、成本分析、导出**全部照常可用**，只是没有智能归因和建议
- 不填 API 密钥也能正常使用平台，只是 Agent 功能不可用

详见 [CLAUDE.md 第 8.4 节 · 数据边界的具体执行](./CLAUDE.md#84-数据边界的具体执行)。

## 怎么装（阶段一完成后适用）

### 第一步：安装 Python

先检查电脑上有没有 Python。

**Windows**：按 `Win + R`，输入 `cmd` 回车，在黑窗口里输入：
```
python --version
```

**macOS**：打开「终端」（在启动台里搜索「终端」），输入：
```
python3 --version
```

显示 `Python 3.11.x` 或更高就跳到第二步。提示找不到命令，就去 [python.org/downloads](https://www.python.org/downloads/) 下载安装。

> ⚠️ **Windows 用户注意**：安装界面最下方有个 **「Add Python to PATH」** 勾选框，**一定要勾上**，否则后面所有命令都会失败。

### 第二步：下载本项目

把项目文件夹放到你找得到的位置，比如 `D:\能碳监测平台` 或 `~/文稿/能碳监测平台`。

### 第三步：安装依赖

**Windows**（在项目文件夹里按住 `Shift` + 右键 → 「在此处打开 PowerShell 窗口」）：
```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

**macOS**（在「终端」里，先 `cd` 到项目文件夹）：
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

这一步会下载几个工具包，要几分钟，最后显示 `Successfully installed ...` 就成功了。

> 💡 `.venv` 是个「独立环境」，把这个项目用的工具包单独装在项目文件夹里，不会影响你电脑上的其他程序。

### 第四步：配置 API 密钥（只有要用 Agent 才需要）

**Windows**
```powershell
copy .env.example .env
```

**macOS**
```bash
cp .env.example .env
```

然后用记事本/文本编辑器打开 `.env`，把密钥填进去。

> 🔒 `.env` 已经在 `.gitignore` 里，不会被提交到仓库。**不要把密钥贴进任何代码文件或聊天记录。**
>
> 跳过这一步也能正常用平台，只是 Agent 功能不可用。

## 出问题了怎么办

| 提示信息 | 什么意思 | 怎么解决 |
|---|---|---|
| `python 不是内部或外部命令` | 电脑找不到 Python | 重装 Python，记得勾「Add Python to PATH」 |
| `ModuleNotFoundError: No module named 'xxx'` | 少装了一个工具包 | 重跑 `pip install -r requirements.txt` |
| `Port 8501 is already in use` | 端口被占用 | 换端口：`streamlit run app.py --server.port 8502` |
| 浏览器没自动打开 | 正常现象 | 手动输入 `http://localhost:8501` |
| 提示「未配置 API 密钥」 | 没填 `.env` | 只影响 Agent，其余功能正常。要用就填密钥 |
| `pip` 下载很慢或超时 | 网络问题 | 换镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 解析出来的数据不对 | PDF/Word 解析本就不保证 100% 准确 | 在「待确认预览区」手工改正再入库，这是设计好的环节 |
| 提示读不到 GPU 功耗 | 机器上没有 NVIDIA 卡或没权限 | 不影响其他功能，改用文件导入台账 |
| 算不出每百万 Token 碳足迹 | 没导入 Token 计量数据 | 核心指标依赖它。没有就只能按时段/任务口径算 |
| 算不出空置率 | 园区结构表没填装机卡数 | 空置率的分母就是它，必填 |
| 空载能耗显示为 0 | 机型台账没填单卡待机功率 | 必须实测填写，用经验值会算错 |
| 储能净减碳算不出来 | 储能记录没填「充电来源」 | 充的是光伏还是市电，直接决定结论正负 |
| 分时绿电比例是空的 | 风光数据只有月度总量，没有时序曲线 | 需要分时出力数据才能做错配分析 |
| 提示「样本不足，结论不可靠」 | 某个任务×机型组合的样本太少 | 正常保护机制，攒够数据再看，别拿它下结论 |

## 重要提醒

⚠️ 内置的**排放因子**是参考值，正式使用前请按你所在地区、年份的官方发布数据核对更新。

⚠️ **电价表和 PUE 必须按你的实际情况填写**，内置值仅为示例，直接用会算错。

⚠️ **Agent 给的是分析建议，不是结论**。碳排放数字以平台的确定性计算为准，Agent 的话请自行核实。

⚠️ **Token 口径行业内尚无统一标准**（输入+输出 vs 仅输出，各家算法不同）。平台强制标注口径，但**跨组织对比仍需谨慎**。

⚠️ **平台只标记「统计上反常」，不判断「业务上是否有问题」**。一次计划内的压测也会被标为突变点，是不是问题由你判断。负荷突增只做时间对齐，**时间上撞在一起不等于因果**。

⚠️ **寿命折损是工程简化模型，不是可靠性物理模型**。平台不预测哪台机器什么时候坏，只给一个可横向比较的相对指标。分档系数默认 0.6/1.0/1.3 是经验值，**必须按你的实际情况校准**。

⚠️ 本平台输出的是**内部分析结果**，不能直接用于 ISO 14064 / ISO 14067 等第三方核证提交。
