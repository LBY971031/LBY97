## 三、⚠️ 读表须知：为什么三段之和是 100%，而上游+中游却超过 100%

下游为**负值**，因为五年残值回收（购置价的 10%）大于报废处置支出（购置价的 2%），净额为 −8% 购置价。

以 A100 × MiniMax-M2.7 在 S0 下为例：

```
上游 83.2%  +  中游 23.5%  +  下游 (−6.7%)  =  100.0%
```

上游与中游之和为 106.7%，超出部分正是由下游的残值回收抵消。
**在论文表格中应将下游列明确标注为净值，并保留负号，避免读者误判合计。**

## 四、四项结构性观察

### 1. 下游占比在 12 个组合中恒为 −6.7%

原因：处置费率（2%）与残值率（10%）均按购置价比例折算，购置价在分子与分母中同时出现：

$$\frac{\text{下游}}{\text{总计}} = \frac{-0.08 \cdot C/N}{1.17 \cdot C/N + E} \approx \frac{-0.08}{1.17} = -6.84\%$$

其中 C 为购置价、N 为寿命内 token 产出、E 为电费。由于电费 E 相对极小，该比值几乎不随配置与情景变化，实际落在 −6.7%。

**推论**：下游占比对配置选型与电力方案完全不敏感，其数值由残值率与处置费率两个假设直接决定。若残值率由 10% 调整为 5%，下游占比将由 −6.7% 变为 −2.5%，是全表对参数最敏感的一项。

### 2. 中游内部仍由运维主导，电费只占中游的 7.0%~11.4%

| 配置 | 情景 | 中游小计 | 电费占中游 | 运维占中游 |
|---|---|---|---|---|
| A100 × MiniMax-M2.7 | S0 | 2.004 | **11.4%** | 88.6% |
| | S1 | 1.978 | 10.3% | 89.7% |
| | S2 | 1.971 | 9.9% | 90.1% |
| H100 × MiMo-V2-Flash | S0 | 3.727 | 8.4% | 91.6% |
| | S1 | 3.692 | 7.5% | 92.5% |
| | S2 | 3.682 | 7.3% | 92.7% |
| H200 × Qwen3.5-397B | S0 | 4.480 | 8.0% | 92.0% |
| | S1 | 4.440 | 7.2% | 92.8% |

**"中游"并不等于"运行相关"**：中游中 88.6%~93.0% 是运维费，而运维费按购置价的 5%·a⁻¹ 计提，本质上仍是上游资本开支的派生项。真正随运行状态变化的只有电费，占中游的 7.0%~11.4%、占总成本的 1.57%~2.67%。

### 3. 上游占比在配置间的差异（83.2%~84.1%）由电费相对权重决定

上游金额与总成本之比，取决于电费相对于购置价的大小：

| 配置 | 购置价 | 电费占总成本（S0） | 上游占比（S0） |
|---|---|---|---|
| A100 × MiniMax-M2.7 | 1.40×10⁶ 元（最低） | **2.67%**（最高） | **83.2%**（最低） |
| B200 × DeepSeek-V4 | 3.60×10⁶ 元 | 2.43% | 83.4% |
| H100 × MiMo-V2-Flash | 2.40×10⁶ 元 | 1.91% | 83.8% |
| H200 × Qwen3.5-397B | 3.00×10⁶ 元 | **1.83%**（最低） | **83.9%**（最高） |

二者呈严格反向关系：电费权重越高，上游占比越低。A100 配置购置价最低，同一度电费在其成本中的相对分量最大，故上游占比最低。

### 4. 绿电方案下上游占比反而升高

| 配置 | 上游 S0 → S1 → S2 | 中游 S0 → S1 → S2 |
|---|---|---|
| A100 × MiniMax-M2.7 | 83.2% → 83.4% → 83.5% | 23.5% → 23.2% → 23.2% |
| H100 × MiMo-V2-Flash | 83.8% → 84.0% → 84.1% | 22.9% → 22.7% → 22.7% |
| H200 × Qwen3.5-397B | 83.9% → 84.1% → 84.1% | 22.8% → 22.6% → 22.6% |
| B200 × DeepSeek-V4 | 83.4% → 83.6% → 83.7% | 23.3% → 23.1% → 23.0% |

机制：绿电方案降低电价，使中游金额与总成本同步下降，而上游金额保持不变，占比因而上升。变化幅度为 0.2~0.3 个百分点。

**这是一个需要在论文中说明的表述陷阱**：不能因"绿电方案下上游占比更高"而推断绿电方案的资本开支更重——上游的绝对金额在三情景下完全相同（7.102 / 13.660 / 16.483 / 8.749 元），变化的只是分母。

## 五、可直接写入论文的一段概括

三种电力接入情景下，单位 token 成本的阶段分布高度一致：上游（购置阶段）占 83.2%~84.1%，中游（运行阶段）占 22.6%~23.5%，下游（退役阶段）为 −6.7%，负值源于五年残值回收（购置价的 10%）高于报废处置支出（购置价的 2%）。中游内部由运维费主导，占该阶段的 88.6%~93.0%，而运维费按购置价的 5%·a⁻¹ 计提，仍属上游资本开支的派生项；真正随运行状态变化的电费仅占中游的 7.0%~11.4%、占总成本的 1.57%~2.67%。由现状电网转向绿电方案后，上游占比自 83.2%~83.9% 微升至 83.5%~84.1%，该变化源于电费下降使分母缩小，上游绝对金额在三情景间保持不变。

## 六、参数敏感性提示

| 参数 | 现取值 | 直接决定 | 敏感性 |
|---|---|---|---|
| 残值率 | 10% | 下游占比 | **高**——降至 5% 则下游由 −6.7% 变为 −2.5% |
| 处置费率 | 2% | 下游占比 | 中 |
| 年运维率 | 5%·a⁻¹ | 中游占比 | **高**——占中游的九成 |
| 综合到户电价 | 0.30~0.35 元·(kW·h)⁻¹ | 中游内部构成 | 低——仅影响中游的 7%~11% |

上述四项中，残值率与年运维率为估计值，且分别主导下游与中游，建议在论文中作为敏感性分析对象或补充取值依据。
