# 记忆档案 32：单位 token 能耗与生命周期分电源发电量的三段总结（精简版）

对应表 N（单台部署各电源累计发电量）与表 M（三情景单位 token 能耗）。
等权场景，单台部署，五年生命周期（30 660 运行小时）。每节各一段。

---

## 第一段　从服务器与运行模型的角度

四组平台–模型配置的单位 token 全站用电量为 0.652~1.026 kW·h·(10⁶ token)⁻¹，极差 1.574 倍，由单位 token 能耗与吞吐率之比决定。GPU 侧仅占整机 IT 侧的 41.8%~63.3%，放大倍数 1.58~2.39 倍并与 GPU 功率呈反向关系，故以 GPU 能耗代理系统能耗时对低功率配置的低估最为严重。两种口径的排序并不一致：B200–DeepSeek-V4 配置的五年累计用电量为 A100–MiniMax-M2.7 配置的 2.332 倍，居四组之首，但其 token 产出达 2.087 倍，单位用电量仅为后者的 1.117 倍。绝对用电量正比于整机功率，单位用电量正比于功率与吞吐率之比，引用时须明确口径。

---

## 第二段　从电力接入情景的角度

三种情景下的单位 token 全站用电量完全相同，差异仅在电源结构与电源侧电量需求。现状电网（S0）与绿电直连 + CCS 火力补电（S2）的五年累计发电量均等于负载侧用电量（12.85~29.96 万 kW·h），燃煤份额由 69.0% 降至 32.0% 且全部配置捕集设施。绿电直连 + 储能补电（S1）是唯一发电量高于负载用电量的情景：储能往返效率为 0.90，交付 32% 的补电电量需自电源侧取用 35.56% 充电，发电量合计达负载用电量的 103.56%，往返损耗占 3.58%。该代价在负载侧计量中不可见而仅在电源侧显现，风光装机容量须按超配后的发电量确定。

---

## 第三段　讨论

上述结果呈现一种近似的正交结构：平台–模型配置决定用电量的大小，电力接入方案决定电量的来源构成——单位 token 用电量在三情景间不变，各电源占比在四组配置间相同，故能效优化与电源结构优化可分别推进而不相互削弱。但该正交性不延伸至碳足迹与成本：隐含碳由整机质量与寿命内产出决定，折旧与运维按购置价计提，二者均不随电源结构变化，故运行侧被绿电削减后，这两个原本次要的分项升至主导地位——S1 情景下隐含碳占总碳的 34.3%~51.3%，购置阶段成本占总成本的 83.4%~84.1%。能耗维度成立的正交性在碳与成本维度被固定项打破，提示评价体系不应止步于单位 token 能耗，该指标无法反映制造环节与资本投入，而二者恰是绿电情景下的主导因素。结论受三项边界制约：计量边界止于数据中心电表，未计线损差异；非 GPU 部件功率为估算值，待 PDU 实测校准；两组吞吐率由功率分布反推，不构成独立观测。
