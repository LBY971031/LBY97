# 记忆档案 32：单位 token 能耗与生命周期分电源发电量的三段总结

对应表 N（单台部署各电源累计发电量）与表 M（三情景单位 token 能耗）。
等权场景（文本 50% : 代码 50%），单台部署，五年生命周期（30 660 运行小时）。
每节各一段。

---

## 第一段　从服务器与运行模型的角度

四组平台–模型配置的单位 token 全站用电量介于 0.652~1.026 kW·h·(10⁶ token)⁻¹，最高值为最低值的 1.574 倍，该指标由单位 token 能耗与吞吐率之比决定：H200–Qwen3.5-397B 配置的加权值分别为 1.625 J·token⁻¹ 与 1 649 tok·s⁻¹，对应 1.026 kW·h·(10⁶ token)⁻¹；A100–MiniMax-M2.7 配置为 0.855 J·token⁻¹ 与 1 786 tok·s⁻¹，对应 0.652 kW·h·(10⁶ token)⁻¹。逐级拆解显示，GPU 侧仅占整机 IT 侧的 41.8%~63.3%，其余来自非 GPU 部件与 PSU 转换损耗，放大倍数 1.58~2.39 倍且与 GPU 功率呈反向关系——非 GPU 功率在各平台间仅相差 1.37 倍而 GPU 功率相差 3.52 倍，故低功率配置承担的固定开销比重更大，这提示以 GPU 能耗代理系统能耗时对低功率配置的低估最为严重；整机 IT 侧至全站的增量固定为 15%，对应 0.085~0.134 kW·h·(10⁶ token)⁻¹。需要注意的是，五年累计口径与单位 token 口径的排序并不一致：B200–DeepSeek-V4 配置的累计用电量为 29.96 万 kW·h，是 A100–MiniMax-M2.7 配置的 2.332 倍，为四组最高，但其 token 产出达后者的 2.087 倍，单位 token 用电量因而仅为后者的 1.117 倍并位列第二低；绝对用电量正比于整机功率，单位 token 用电量正比于功率与吞吐率之比，引用时须明确口径。

---

## 第二段　从电力接入情景的角度

三种电力接入情景下的单位 token 全站用电量完全相同，差异仅体现在电源结构与电源侧电量需求上：现状电网情景（S0）的五年累计发电量等于负载侧用电量（12.85~29.96 万 kW·h），由燃煤火电 69.0%、风电 22.0% 与光伏 9.0% 构成；绿电直连 + CCS 火力补电情景（S2）的发电量合计同样等于负载用电量，由风电 40.8%、光伏 27.2% 与 CCS 火电 32.0% 构成，燃煤份额由 69.0% 降至 32.0% 且全部配置捕集设施；绿电直连 + 储能补电情景（S1）则是唯一发电量高于负载用电量的情景，因储能往返效率为 0.90，为交付 32% 的补电电量需自电源侧取用 35.56% 用于充电，发电量合计达负载用电量的 103.56%，即 13.31~31.02 万 kW·h，其中储能充电量 4.57~10.65 万 kW·h、放电量 4.11~9.59 万 kW·h、往返损耗 0.46~1.07 万 kW·h（占负载用电量的 3.58%），其余 8.74~20.37 万 kW·h 由绿电直供，电量平衡关系为「发电量合计 = 绿电直供量 + 储能充电量」与「负载用电量 = 绿电直供量 + 储能放电量」。由此可见，储能方案的电量代价在负载侧计量中不可见而仅在电源侧显现，风光装机容量的确定须使用超配后的发电量合计，否则将出现 3.56% 的电量缺口。

## 第三段　讨论

综合前两段可识别出一种近似的正交结构：平台–模型配置决定用电量的大小，电力接入方案决定电量的来源构成，二者互不干涉——单位 token 用电量在三情景间保持不变，说明该指标仅对配置敏感；各电源的发电量占比在四组配置间完全相同，说明电源结构仅对情景敏感；其工程含义是能效优化与电源结构优化可分别推进而不相互削弱，例如在 S1 情景下将配置由 H200–Qwen3.5-397B 更换为 A100–MiniMax-M2.7，负载用电量下降 31.2%，储能规模、风光装机与超配电量随之等比缩减。然而该正交性并不延伸至碳足迹与成本：隐含碳由整机质量与寿命内 token 产出决定，折旧与运维按购置价计提，二者均不随电源结构变化，因此当运行侧被绿电大幅削减后，这两个原本次要的分项会升至主导地位——S1 情景下隐含碳占总碳的 34.3%~51.3%，购置阶段成本占总成本的 83.4%~84.1%——**能耗维度上成立的正交性，在碳与成本维度被这两个固定项打破**，这提示评价体系不应止步于单位 token 能耗，该指标虽物理意义清晰且对配置敏感，却无法反映制造环节与资本投入，而二者恰是绿电情景下的主导因素。上述结论受三项边界制约：计量边界为数据中心电表，未计入公共电网线损（约 5%~6%）与绿电专线线损（约 1%~2%）的差异，该修正将扩大 S0 与绿电方案在电源侧的差距；非 GPU 部件功率取 1.9~2.6 kW 系按部件构成估算，尚待 PDU 实测校准，其直接决定 1.58~2.39 倍的放大关系；MiMo-V2-Flash 与 Qwen3.5-397B 的吞吐率由功率分布反推获得，不构成独立观测，不确定度约 2.4 倍并按反比关系传导至单位 token 用电量。
