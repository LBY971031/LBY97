## 改写稿

### 第一段　购置阶段成本的主导地位及其对配置选型的含义

表 N 汇总了三种电力接入情景下四组平台–模型配置的单位 token 成本及其阶段构成。在现状电网情景（S0）下，购置阶段成本占总成本的 83.2%~83.9%，四组配置间的差异不足 0.7 个百分点；运行阶段占 22.8%~23.5%，退役阶段净值为 −6.7%。由于运维费按购置价的 5%·a⁻¹ 计提、退役处置费与残值回收亦按购置价比例折算，与购置决策直接关联的成本合计占 97.3%~98.2%，而随运行状态变化的电费仅占 1.83%~2.67%。四组配置的单位 token 成本介于 8.538~19.644 元·(10⁶ token)⁻¹，最高值为最低值的 2.30 倍。上述比例在四组配置间的高度一致性表明，该成本结构主要由核算框架本身决定，受具体参数取值的影响有限。

进一步考察配置间差异的来源。A100–MiniMax-M2.7 配置的单位 token 成本最低（8.538 元），其电费贡献仅 0.228 元，而购置价为四者最低（1.40×10⁶ 元），五年累计 token 产出为 1.97×10¹¹。B200–DeepSeek-V4 配置购置价最高（3.60×10⁶ 元），但凭借 4.11×10¹¹ 的累计产出，单位成本降至 10.491 元。H200–Qwen3.5-397B 配置的购置价为 3.00×10⁶ 元，Qwen3.5-397B 在代码场景下的单位 token 能耗为 2.18 J·token⁻¹、跨场景放大倍数为 2.04，等权加权后吞吐率仅 1 649 tok·s⁻¹，购置价偏高与产出偏低两项因素叠加，使其单位成本达 19.644 元。这一结果提示，模型的能效特性主要通过吞吐率改变购置成本的分摊基数进入成本核算，而非经由电费直接作用于成本。据此推断，提高年利用率或改善吞吐率可按比例稀释占比 97% 以上的成本项，而将电费降至零至多使总成本下降 2.7%。

### 第二段　电力接入情景对成本的影响及其局限

将现状电网纳入对比后，两种绿电方案的综合到户电价均低于常规电网：S1（绿电直连+储能补电）为 0.311 0 元·(kW·h)⁻¹，S2（绿电直连+CCS 火力补电）为 0.300 0 元·(kW·h)⁻¹，相对 S0 的 0.350 0 元·(kW·h)⁻¹ 分别下降 11.1% 与 14.3%。这一价差可能来自两方面：其一，绿电直连采用专线物理直供，可规避或减免公共电网输配电价，该项在蒙西大工业到户电价中约占 0.08~0.12 元·(kW·h)⁻¹；其二，蒙西风电年利用小时数为 2 800~3 200 h（全国平均约 2 200 h），资源条件使绿电平准化度电成本低于当地火电上网电价。需要说明的是，上述电价构成为基于公开区域电价结构的估算，实际值取决于接入电压等级、变压器容量与市场化交易签约价格。

然而，该电价优势在总成本口径下被显著稀释。由于电力接入方案仅影响运行阶段中的电费一项，而电费占总成本比重不足 2.7%，11.1%~14.3% 的电价降幅传导至单位 token 总成本后仅为 0.20%~0.38%；两种绿电方案之间的差异更小，为 0.06%~0.08%。以五年整机口径计，四组配置的总成本为 1.683×10⁶~4.317×10⁶ 元，其中电费为 4.5×10⁴~1.05×10⁵ 元，由现状电网切换至绿电方案可节省 6×10³~1.5×10⁴ 元。由此可见，同一电力方案下四组配置的成本相对差异达 130%，而同一配置下三种电力方案间的相对差异不超过 0.38%，前者约为后者的 340 倍。这一量级关系表明，在本文设定的核算边界内，平台–模型配置的选择对单位 token 成本具有一阶影响，电力接入方案的优化则属二阶问题。需要指出的是，三种情景在碳足迹上的差异未反映于成本核算中，相关评价需另行开展；同时，本结论建立在"数据中心向售电方购电、配套电源投资通过度电价格传导"的商业模式假设之上，若采用自建配套电源模式，相应投资将由运行阶段转移至购置阶段，上述比例关系需重新核算。

## 结构选择说明

- **观测先于解释**：每段首句为该段的核心命题，随后给出支撑数据，解释性语句统一后置并以提示性动词引导，避免读者将推断误读为观测。
- **保留两段但内部分层**：按要求维持两段结构；严格的 Results / Discussion 分离建议见下节。
- **数量级对比作为收束**：第二段以"一阶/二阶"的量级判断收尾，替代原文的实务建议，使结论停留在本文证据能够支撑的范围内。
- **边界条件前置声明**：电价估算的不确定性在引入数据的同一段落内声明，而非留到全文末尾。
