# 记忆档案 27：三种电力接入情景下的单位能耗

## 结论先行

**终端全站用电量在 S0、S1、S2 三种情景下完全相同。**

这不是计算疏漏，而是边界设定的必然结果：电力接入方案改变的是"电从哪里来"，
而非"用了多少电"。服务器的耗电量由 J/token、吞吐率、非 GPU 部件功率、PSU 效率与 PUE 决定，
这五项均与电源结构无关。

因此能耗结果需分两个口径报告：

| 口径 | 三情景是否相同 | 说明 |
|---|---|---|
| **终端全站用电量** | ✅ 相同 | 数据中心电表计量的用电量 |
| **电源侧电量需求** | ❌ 不同 | 为满足同样的终端用电，各情景在发电侧所需的电量与结构不同 |

## 三、三点说明

### 1. S1 的绿电超配是储能方案的隐性代价

为向负载交付 1 kW·h，S1 需要 1.035 6 kW·h 的绿电发电量，超出部分（3.56%）在储能充放电过程中损失。
按五年整机口径，四组配置的超配量分别为 0.46、0.56、0.66、1.07 万 kW·h。

**这一项在只看排放因子时是不可见的**——EF 已将该损耗折算进等效系数，
但风光装机规模的确定必须使用超配后的电量。若按终端用电量配置风光容量，将出现 3.56% 的电量缺口。

### 2. S2 无往返损耗，但补电部分的碳强度高

S2 的电源侧需求合计为 1.000 0，与终端用电相等，不存在超配。代价体现在结构上：
32% 的电量来自 CCS 火电（碳排放因子 0.22 kg CO₂-eq·(kW·h)⁻¹），
而 S1 的补电部分来自储能放电，其等效因子仅为 0.038 8 kg CO₂-eq·(kW·h)⁻¹。

**两种方案的取舍是"电量损耗"与"碳强度"之间的交换**：S1 多用 3.56% 的电，换取补电环节碳强度下降约 82%。

### 3. 若将边界延伸至电网线损，S0 的电源侧需求会进一步上升

本表以数据中心电表为计量边界。若按发电侧口径核算，S0 的电量需经公共电网输送，
需计入线损（蒙西电网综合线损率约 5%~6%）；而 S1、S2 的绿电部分经专线直供，线损显著更低（约 1%~2%）。
**该修正将进一步扩大 S0 与绿电方案在电源侧电量需求上的差距，本文未纳入，属于边界收窄。**

## 四、可直接写入论文的一段

三种电力接入情景下的终端全站用电量完全相同，为 0.652~1.026 kW·h·(10⁶ token)⁻¹，
其中 GPU 侧占 0.237~0.451 kW·h·(10⁶ token)⁻¹，非 GPU 部件与 PSU 损耗使其放大 1.58~2.39 倍，
PUE 再引入 15% 的增量。该一致性源于核算边界的设定：电力接入方案决定电量的来源结构，
而不改变服务器的用电量。差异体现在电源侧：S0 的电网购电量与终端用电量相等；
S1 因储能往返效率为 90%，绿电需求系数为 1.035 6，即需超配 3.56% 方能满足同等负载，
按五年整机口径对应 0.46~1.07 万 kW·h 的额外发电量；S2 的电源侧需求系数为 1.000 0，
由 68% 绿电与 32% CCS 火电构成，无往返损耗但补电环节的碳强度相应提高。
上述结果表明，储能方案与 CCS 方案的差异并非体现在终端能耗，而是体现在电量损耗与碳强度之间的权衡。

## 五、参数依赖

| 参数 | 取值 | 影响 |
|---|---|---|
| 绿电直供比例 α | 68% | 决定 S1 超配量与 S2 的绿电/火电配比；α 越高，两情景的电源侧差异越小 |
| 储能往返效率 η | 90% | 仅影响 S1；η 降至 85% 时超配量升至 5.65% |
| PUE | 1.15 | 三情景相同，等比例作用于全部结果 |
| 非 GPU 部件功率 | 1.9~2.6 kW | 决定 GPU 侧到整机侧的放大倍数，为待 PDU 实测项 |
