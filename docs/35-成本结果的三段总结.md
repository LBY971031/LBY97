# 记忆档案 35：成本结果的三段总结

对应表 1（单位 Token 成本）与表 2（服务器生命周期总成本）。
等权场景（文本 50% : 代码 50%），单台部署，五年生命周期。成本口径仅含财务支出，不含碳价。每节各一段。

---

## 第一段　从服务器与运行模型的角度

四组平台–模型配置的单位 token 成本在现状电网情景下为 8.538~19.644 元·(10⁶ token)⁻¹，极差 2.301 倍，其构成在三种电力情景下高度一致：购置阶段占 83.2%~84.1%，运行阶段占 22.6%~23.5%，退役阶段为 −6.7%（负值源于五年残值回收高于报废处置支出，故三阶段之和为 100% 而前两阶段之和超出 100%）。由于运维费按购置价的 5%·a⁻¹ 计提、退役处置与残值亦按购置价比例折算，与购置决策直接关联的成本合计占 97.3%~98.4%，独立于购置决策的电费仅占 1.57%~2.67%。该结构使单位成本近似等于购置价与寿命内 token 产出之比：H200–Qwen3.5-397B 配置购置价为 3.00×10⁶ 元而五年产出仅 1.82×10¹¹，单位成本达 19.644 元；A100–MiniMax-M2.7 配置以 1.40×10⁶ 元的最低购置价取得 1.97×10¹¹ 产出，单位成本降至 8.538 元。两种口径的排序不一致：总成本排序为 A100 < H100 < H200 < B200，与购置价同序，极差 2.565 倍；单位成本排序为 A100 < B200 < H100 < H200。B200–DeepSeek-V4 配置的五年总成本 431.69 万元为四组最高，但其产出达 4.11×10¹¹，单位成本 10.491 元位列第二低。

---

## 第二段　从电力接入情景的角度

电力接入方案仅影响运行阶段中的电费一项，其余四个科目在三情景间完全相同。三种情景的综合到户电价分别为 0.350 0（S0 现状电网）、0.311 0（S1 绿电直连 + 储能补电）与 0.300 0 元·(kW·h)⁻¹（S2 绿电直连 + CCS 火力补电），两种绿电方案较现状电网分别低 11.1% 与 14.3%；其中 S1 的电价可由等效电价直接计算，亦可分解为绿电购电量（负载电量的 103.56%）乘以绿电单价 0.22 加储能设施费（放电量乘以 0.26），两式等价，故储能位于站内所致的电量增量已内含于电价，不需另行计入。五年电费为 3.86~10.49 万元，占生命周期总成本的 1.57%~2.67%。由于该占比极低，11.1%~14.3% 的电价降幅传导至单位 token 成本后仅为 0.20%~0.39%，对应总成本减少 0.50~1.50 万元；两种绿电方案之间的差异更小，S1 较 S2 高 0.055%~0.082%，绝对值为 0.142~0.330 万元。

---

## 第三段　讨论

综合两段结果，成本维度呈现比能耗维度更强的单因素支配：平台–模型配置决定 97.3%~98.4% 的成本，电力接入方案仅能作用于其余不足 2.7% 的电费。量化对比可见，同一电力方案下四组配置的单位成本相对差异达 130%，而同一配置下三种电力方案间的差异不超过 0.39%，前者约为后者的 333 倍。这一量级关系提示，绿色算力的成本优化应以配置选型为一阶问题、以电力接入为二阶问题；同时也说明电价信号不足以驱动电源结构的选择——即便绿电已比常规电网便宜 11.1%~14.3%，节省金额相对于资本开支仍属微量，企业缺乏足够动力承担专线建设、购电协议谈判与储能配置的协调成本。更值得注意的是总成本与单位成本排序的分离：前者由购置价决定并与之同序，后者由购置价与寿命内产出之比决定，二者在 B200–DeepSeek-V4 配置上给出相反结论。**这意味着采购预算约束与运营效率目标可能指向不同选择，需在决策中明确以何者为准。** 上述结论受三项参数制约：残值率取 10%、处置费率取 2%，二者共同决定退役阶段的 −6.7%，其中残值率对结果影响最大；年运维率取 5%·a⁻¹，占运行阶段成本的九成；购置价为市场估值，须按实际采购合同替换。三者均为估计值，建议作为敏感性分析对象。
